# Подключение Telegram

## 1. Бот

1. В @BotFather: `/newbot` → получите токен.
2. В `.env` сервера: `BOT_TOKEN=<токен>`. Никуда больше токен не копируйте (код, README, скриншоты, чаты).
3. Если токен утёк — `/revoke` в @BotFather и обновите `.env`.

## 2. HTTPS-адрес Mini App

Telegram открывает Mini App только по HTTPS. Варианты:
- production: домен + HTTPS-прокси (Caddy: `your-domain { reverse_proxy app:8080 }`);
- разработка: туннель `cloudflared tunnel --url http://localhost:5173` (Vite проксирует `/api` на 8080).

Укажите адрес: `WEBAPP_URL=https://your-domain`.

## 3. Режим бота

| Режим | Когда | Настройки |
|---|---|---|
| `webhook` | production | `BOT_MODE=webhook`, `TELEGRAM_WEBHOOK_SECRET=<16+ символов [A-Za-z0-9_-]>`, при другом домене API — `PUBLIC_API_URL` |
| `polling` | локально / без публичного адреса | `BOT_MODE=polling` |
| `off` | бот запущен отдельно или не нужен | — |

При старте API сам: регистрирует webhook `<URL>/telegram/webhook` с секретом (Telegram присылает его в `X-Telegram-Bot-Api-Secret-Token`, чужие запросы отклоняются), ставит команды `/start /help /stop` и меню-кнопку «Заюш ПДД».

Отдельный процесс бота без БД: `npm run dev -w @zayush/bot` (только приветствие и кнопка; для уведомлений бот должен работать внутри API).

## 4. Mini App в @BotFather (опционально)

*Bot Settings → Configure Mini App → Enable* → URL = `WEBAPP_URL`. Появится прямая ссылка `https://t.me/<bot>/<app>` и кнопка «Открыть» в профиле бота.

## 5. Админы

`ADMIN_TELEGRAM_IDS=123456789,987654321` (ID узнать у @userinfobot). Админ видит пункт «Админ-панель» в профиле. Из обычного браузера — `https://your-domain/admin` + `ADMIN_API_TOKEN`.

## Обязательная подписка

### Права бота
- **Канал:** добавьте бота **администратором** (достаточно минимальных прав). Telegram отдаёт `getChatMember` по каналам только администраторам.
- **Группа/супергруппа:** бот должен быть **участником**; надёжнее — администратором (в больших группах со скрытым списком участников иначе может не работать).
- Без этого проверка вернёт ошибку конфигурации — она видна только в логах сервера, пользователю показывается «Telegram не отвечает, попробуйте позже».

### Идентификаторы
- Публичный канал/группа: `@username`, ссылку можно не указывать (будет `https://t.me/username`).
- Закрытый: числовой id `-100…` (перешлите сообщение боту @getidsbot или посмотрите в логах `my_chat_member`) **и** ссылка-приглашение, созданная владельцем. Приложение не угадывает ссылки.

### Настройка
Через `.env` (переносится в БД при первом старте) или `/admin → Подписка`:
```env
REQUIRE_SUBSCRIPTION=true
REQUIRED_CHANNELS=@zayush_channel||Канал Заюша
REQUIRED_GROUPS=-1001234567890|https://t.me/+AbCdEf|Чат Заюша
```
Выключение: тумблер в админке или `REQUIRE_SUBSCRIPTION=false` (если в админке значение ещё не меняли). Статусы `member`, `administrator`, `creator`, `restricted (is_member=true)` считаются подпиской; `left`, `kicked` — нет.

## Уведомления

`REMINDERS_ENABLED=true`, `REMINDER_HOUR_MSK=19`. Напоминание получают только те, кто нажал /start (или разрешил боту писать) **и** включил уведомления в настройках приложения. `/stop` выключает. Пользователи, заблокировавшие бота, автоматически исключаются.
