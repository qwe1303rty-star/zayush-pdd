# Контент: вопросы, знаки, объяснения

## Принцип

Каждый материал = **милая сценка** (поле `scene`, не влияет на смысл) + **настоящий вопрос ПДД** + **серьёзный разбор** (`explanation`, `whyWrong` для каждого неверного варианта, `clauseRefs`, `signRefs`, `takeaway`).
Номера пунктов и знаков указываются только если подтверждены по тексту ПДД. Не уверены — оставьте пустым.

## Источники

- ПДД РФ — постановление Совета Министров — Правительства РФ от 23.10.1993 № 1090 (официальный текст: pravo.gov.ru, КонсультантПлюс).
- Знаки — Приложение 1 к ПДД; изображения — ГОСТ Р 52290-2024 (действует с 01.01.2026).
- Экзамен — ПП РФ от 24.10.2014 № 1097, приказ МВД от 20.02.2021 № 80.

Набор pdd_russia обновлён 02.09.2026 (2026.q3). Последнее изменение ПДД — редакция от 08.09.2026 — касается только примечания к п. 2.1.1 и на вопросы билетов не влияет.

## Откуда берутся вопросы

`content/abm/content.json` собирается скриптом из открытого набора [etspring/pdd_russia](https://github.com/etspring/pdd_russia) (40 билетов A, B, M, знаки, разметка):

```bash
git clone --depth 1 https://github.com/etspring/pdd_russia ../pdd_russia
node scripts/build-abm-content.mjs ../pdd_russia   # → content/abm/content.json + apps/web/public/pdd/*
npm run db:seed
```

Что берётся из набора: официальный текст вопроса (поле `officialText`, показывается в экзамене), варианты и правильный ответ, картинка билета, пояснение (`explanation`), тема. Номера пунктов ПДД и знаков (`clauseRefs`, `signRefs`) и подсказка извлекаются из пояснения автоматически. Блок экзамена — по позиции вопроса в билете (1–5, 6–10, 11–15, 16–20).

Наше: формулировка в стиле «Заюш» — `content/abm/style/*.json`, ключ `«билет-вопрос»` (например `"3-12"`). Правила стиля:
- обращения: заюш, кисуль, красотка; «масик» — парень героини, а не обращение к ней; никаких «котиков» и «коть»;
- бытовая подводка (ноготочки, салон, кофе, масик) + сам вопрос, переведённый на «ты»;
- **нельзя** добавлять в подводку дорожные обстоятельства, которых нет в билете (знаки, полосы, погоду, место);
- если вопрос оканчивается двоеточием — оставить окончание, чтобы варианты ответа его продолжали.

Описания знаков, которых нет в наборе, и бытовые примеры к знакам — `content/sign-notes.json`. Проверенная база помощника — `content/knowledge.json`.

При обновлении набора (раз в квартал) повторите сборку и `npm run db:seed`: вопросы обновятся по `externalId` (`abm-<билет>-<вопрос>`), прогресс пользователей сохранится. Новые вопросы без формулировки «Заюш» скрипт перечислит — допишите их в `style/*.json`.

## Формат файла

См. `content/abm/content.json`:

```jsonc
{
  "set": { "code": "abm-2026", "title": "…", "isDemo": false },
  "sources": { "pdd": "https://…" },
  "topics": [{ "slug": "signs", "title": "Дорожные знаки", "examBlock": 1, "sortOrder": 1 }],
  "tickets": [{ "number": 1, "title": "Билет 1", "questions": ["abm-01-01", "…"] }],
  "questions": [{
    "externalId": "abm-01-01",          // стабильный ключ: повторный импорт обновляет вопрос
    "topic": "signs",
    "scene": "Зайка…",                   // опционально
    "hint": "Смотри п. 12.4…",           // подсказка до ответа: наводит, но не называет ответ
    "text": "Что обозначает этот знак?",
    "imageUrl": "/pdd/abm/<файл>.jpg",   // /pdd/abm, /pdd/signs, /uploads или null
    "imageAlt": "…",
    "options": [
      { "text": "…", "correct": true },
      { "text": "…", "whyWrong": "…" }
    ],
    "explanation": "…",
    "takeaway": "…",
    "clauseRefs": ["12.4"],
    "signRefs": ["5.16"]
  }],
  "signs": [{ "code": "5.16", "title": "…", "category": "special", "description": "…", "imageUrl": "/pdd/signs/5.16.svg", "imageVerified": false }],
  "knowledge": [{ "externalId": "kb-…", "title": "…", "keywords": ["…"], "answer": "…", "clauseRefs": [], "signRefs": [] }]
}
```

Правила валидации: 2–5 вариантов, ровно один правильный, есть объяснение, тема существует, пункты вида `10.2` / `2.1.2`.

## Импорт

```bash
npm run content:import -- my-content.json --dry-run   # только проверка
npm run content:import -- my-content.json             # импорт (upsert по externalId)
```
Или `/admin → Импорт`. Прогресс пользователей сохраняется: варианты ответа обновляются на месте, а не пересоздаются.

## Экзаменационные блоки

Экзамен берёт вопросы по `Topic.examBlock` (1–4). Для экзамена «как в ГИБДД» в каждом блоке нужно ≥ 10 вопросов (5 основных + 5 дополнительных). Для официальных билетов удобно завести 4 темы-блока по позициям 1–5, 6–10, 11–15, 16–20 либо назначить блоки существующим темам.

## Иллюстрации

- Картинки билетов — из набора (`apps/web/public/pdd/abm`), знаков и разметки — `apps/web/public/pdd/signs`, `apps/web/public/pdd/markup` (имя файла = номер).
- Знаки без изображения в наборе получают заглушку с номером. Загрузите настоящее изображение в админке (Знаки → Изображение) и отметьте «Сверено с ГОСТ».
- Свои картинки: `/admin → Вопросы → Загрузить` (PNG/JPEG/WebP до 2 МБ).

## Чек-лист проверки вопроса

1. Правильный ответ следует из конкретного пункта ПДД — пункт указан и перепроверен.
2. Номер и название знака совпадают с Приложением 1.
3. Картинка содержит всё, что нужно для ответа, и ничего лишнего.
4. Для каждого неверного варианта есть объяснение.
5. Шутка не искажает правило.
6. Подсказка наводит на пункт или признак, но не называет правильный вариант.
