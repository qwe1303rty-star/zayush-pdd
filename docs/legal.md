# Соответствие законодательству РФ

Что уже сделано в коде и что владелец должен сделать сам перед публичным запуском.
Это рабочий чек-лист, а не юридическое заключение: перед запуском покажите документы юристу.

## 1. Персональные данные — 152-ФЗ

### Сделано в приложении

| Требование | Где реализовано |
|---|---|
| Согласие до начала обработки, отдельным документом (ст. 9, с 01.09.2025 — отдельно от других документов) | Экран согласия `apps/web/src/pages/Legal.tsx`, документ `/legal/consent`. Учётная запись создаётся только в `POST /api/consent` |
| Подтверждение получения согласия (ч. 3 ст. 9) | Таблица `ConsentLog`: дата, версия, HMAC-хэш Telegram ID |
| Повторное согласие при изменении документов | `CONSENT_VERSION` в `packages/shared/src/legal.ts` — при увеличении все увидят экран заново |
| Публичная политика обработки (ч. 2 ст. 18.1) | `/legal/privacy` — доступна без входа, ссылка в боте (`/privacy`) и в настройках |
| Минимизация (ч. 5 ст. 5) | Храним только Telegram ID, имя и учебные данные. Username, язык, IP не храним; IP и query-строки не пишутся в логи |
| Отзыв согласия и удаление (ст. 21) | Настройки → «Удалить аккаунт и данные» (`DELETE /api/me`), каскадное удаление сразу |
| Сроки хранения (ч. 7 ст. 5) | Автоудаление аккаунтов без входа `RETENTION_INACTIVE_DAYS` (по умолчанию 3 года), очистка кодов и журнала согласий — `services/retention.ts` |
| Бот не создаёт запись без согласия | `/start` только отмечает `botCanWrite` у существующих пользователей |
| Запуск в production без данных оператора невозможен | Проверка в `apps/api/src/env.ts` |

### Сделать владельцу

1. **Определить оператора** (самозанятый, ИП или ООО) и заполнить `LEGAL_OPERATOR_*`, `LEGAL_CONTACT_EMAIL`, `PD_HASH_SECRET` в `.env`.
2. **Подать уведомление в Роскомнадзор** об обработке ПДн (ст. 22) на [pd.rkn.gov.ru](https://pd.rkn.gov.ru) до начала обработки. В уведомлении отметьте трансграничную передачу (Telegram; при включённом AI — Anthropic) — с 01.03.2023 о ней уведомляют отдельно и заранее (ч. 3–4 ст. 12). Штрафы за отсутствие уведомления — ч. 10 ст. 13.11 КоАП.
3. **Сервер и база данных — в России** (ч. 5 ст. 18): российский хостинг, `LEGAL_SERVER_LOCATION=Российская Федерация`.
4. **Внутренние документы** (ст. 18.1, 19): приказ о назначении ответственного за обработку ПДн, положение об обработке ПДн, перечень лиц с доступом, оценка вреда, модель угроз (для небольшого проекта — упрощённые). Хранятся у оператора, публиковать не нужно.
5. **BotFather → Bot Settings → Privacy Policy**: укажите `https://<ваш-домен>/legal/privacy`.
6. Отвечайте на письма субъектов в течение 10 рабочих дней (ст. 14, 20).

## 2. Российские способы входа — 149-ФЗ

С 01.12.2023 сайты и приложения, где нужна авторизация, обязаны пускать пользователей из России только через российский номер телефона, Госуслуги, ЕБС или иную российскую систему (ч. 10 ст. 8 149-ФЗ). С 07.07.2026 за нарушение — штраф по ст. 13.55 КоАП (граждане 10–20 тыс. ₽, должностные лица 30–50 тыс. ₽, юрлица 500–700 тыс. ₽).

Вход в Mini App идёт через Telegram — иностранный сервис. Поэтому есть режим подтверждения российского номера по SMS:

```
AUTH_RU_PHONE_REQUIRED=true
SMS_PROVIDER=smsru
SMSRU_API_ID=<ключ из личного кабинета sms.ru>
```

После согласия пользователь вводит номер +7 9XX…, получает код, и только потом попадает в приложение. В базе хранится лишь HMAC-хэш номера. В production при выключенном режиме сервер пишет предупреждение в лог.

Применимость требования к Mini App внутри Telegram прямо в законе не разобрана — **рекомендуем включить режим** для публичного запуска.

## 3. Защита детей — 436-ФЗ

Маркировка **12+**: заставка, экран согласия, документы, сообщение бота `/start`, «О приложении». Константа `AGE_RATING` в `packages/shared/src/legal.ts`. Контент без запрещённой информации; при изменении содержания пересмотрите маркировку.

## 4. Русский язык — 168-ФЗ (с 01.03.2026)

Интерфейс на русском. Иностранные слова без словарной нормы заменены: «XP» → «баллы», «бьюти-салон» → «салон красоты», «нейл-бар» → «студия маникюра», «лук» → «образ», «Гелик» → «машинка / внедорожник». Используются слова из орфографического словаря (маникюр, шопинг, фитнес, бутик, селфи). В коде переменные по-прежнему называются `xp` — пользователь их не видит.

## 6. Прочее

- **Реклама (38-ФЗ):** если в боте или канале появится реклама — маркировка и токен ERID через ОРД.
- **Платные функции:** при монетизации понадобятся оферта, правила возврата и онлайн-касса (54-ФЗ).
- **Экзамен:** приложение прямо сообщает, что не является сервисом МВД и не гарантирует сдачу.
